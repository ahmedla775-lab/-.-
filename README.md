# نجاح.كوم

منصة عربية تهدف إلى تلبية حاجات الناس في عالم التكنولوجيا، من خلال أقسام تعليمية وخدمية وتجارية ومهنية.

## الأقسام
- مهن وحرف
- تعلم لغات أجنبية
- تعلم لغات البرمجة
- لنتواصل مع بعض
- بحث عن وظيفة
- مركز تجاري
- علوم أكاديمية

## المميزات
- واجهة عربية RTL.
- تصميم احترافي مع خلفية ديناميكية.
- متجاوب مع الهاتف والكمبيوتر.
- مناسب للنشر على GitHub وVercel.

## التقنيات المستخدمة
- HTML
- CSS
- JavaScript

## طريقة التشغيل
1. حمّل الملفات داخل مجلد واحد.
2. افتح ملف `index.html` في المتصفح.
3. أو ارفع المشروع إلى GitHub ثم اربطه بـ Vercel.

## النشر على Vercel
1. ارفع المشروع إلى GitHub.
2. ادخل إلى Vercel.
3. اختر المستودع.
4. اضغط Deploy.
