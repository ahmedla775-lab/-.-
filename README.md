# نجاح.كوم

منصة عربية حديثة تهدف إلى تلبية حاجات الناس في عالم التكنولوجيا، من خلال جمع التعليم، المهن، الوظائف، اللغات، والتجارة الرقمية في مكان واحد بتصميم احترافي يدعم الهاتف المحمول بشكل ممتاز.

---

## نبذة عن المشروع

**نجاح.كوم** هو موقع عربي تفاعلي بواجهة RTL، مصمم ليكون بوابة شاملة للمحتوى والخدمات التقنية والتعليمية والمهنية.  
يضم الموقع أقسامًا متعددة مثل تعلم اللغات، تعلم البرمجة، البحث عن وظيفة، العلوم الأكاديمية، والمركز التجاري، مع تصميم عصري وخلفية فاخرة مناسبة للموبايل والكمبيوتر.

---

## الأقسام الرئيسية

- مهن وحرف
- تعلم لغات أجنبية
- تعلم لغات البرمجة
- لنتواصل مع بعض
- بحث عن وظيفة
- مركز تجاري
- علوم أكاديمية

---

## المميزات

- تصميم عربي كامل يدعم RTL.
- واجهة حديثة وفاخرة مع ألوان داكنة أنيقة.
- دعم ممتاز للهواتف المحمولة والأجهزة اللوحية.
- قائمة تنقل متجاوبة تظهر بشكل جانبي على الشاشات الصغيرة.
- بطاقات محتوى مرنة وسهلة القراءة.
- صور داخلية لكل قسم لزيادة جاذبية الواجهة.
- نموذج تواصل بسيط وسهل الاستخدام.
- مناسب للنشر على GitHub Pages أو Vercel.
